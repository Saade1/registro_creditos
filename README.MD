# 📌 Registro de Créditos

Este proyecto es una aplicación web para gestionar créditos, desarrollada con **Python-Flask**, **SQLite** y **Chart.js** para la visualización de datos.

## 🚀 Instalación y Configuración

### 📌 Requisitos previos:
- **Python 3.x** instalado
- **Pip** para instalar dependencias
- **Flask y otras librerías** necesarias
- **SQLite** como base de datos

### 🔹 1. Clonar el repositorio
GitHub clónalo con:

```bash
git clone https://github.com/Saade1/registro_creditos.git
cd registro_creditos

python -m venv venv
venv\Scripts\activate  # En Windows
source venv/bin/activate  # En Mac/Linux

pip install -r requirements.txt  # Instalar dependencias

python credits.py  # Configurar la base de datos
python app.py  # Iniciar el servidor
